Deskripsi & Tanggung Jawab

PT Digital Kreasi Nusantara adalah perusahaan rintisan teknologi yang bergerak di bidang solusi fintech dan e-commerce. Kami mengundang talenta berbakat untuk berkolaborasi dalam mengembangkan aplikasi web berkinerja tinggi.

Tanggung Jawab Utama:

  • Membangun arsitektur komponen frontend yang bersih, modular, dan teruji dengan Next.js App Router.
  • Melakukan integrasi API GraphQL dan RESTful secara aman dan efisien.
  • Mengoptimalkan Core Web Vitals, SEO teknis, dan responsive UX pada semua perangkat.
  • Melakukan code review berkala dan memberikan bimbingan teknis kepada junior engineer.

Kualifikasi Pelamar:

  • Pengalaman kerja minimal 3 tahun dalam frontend development dengan ekosistem React/TypeScript.
  • Memahami Tailwind CSS, CSS Modules, dan State Management modern (Zustand/Redux Toolkit).
  • Terbiasa dengan Git, Docker, serta testing automated (Jest/Playwright).
  • Komunikasi baik dan terbiasa bekerja secara mandiri maupun kolaboratif dalam tim.
